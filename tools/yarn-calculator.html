Common questions

How much yarn for a baby blanket?

A 30 × 40 inch baby blanket in worsted weight single crochet needs roughly 900-1,000 yards, about 4-5 standard skeins. Open stitches like granny squares use noticeably less; dense stitches use more.

How much yarn for a throw blanket?

A 50 × 60 inch throw in worsted weight comes in around 2,200-2,500 yards, or 10-12 skeins. In chunky yarn the yardage drops but the skeins are usually shorter, so the count stays similar.

Does crochet use more yarn than knitting?

Generally yes, crochet stitches wrap more yarn per stitch. As a rule of thumb crochet uses 20-30% more yarn than knitting for the same size piece, which this calculator accounts for in the stitch selector.

Why does the calculator add a margin?

Because gauge is personal. Tension, hook size and how you hold the yarn all shift the total, and running short at the last row is the worst outcome. The recommended 12% covers most of that variation.

Is this exact?

No calculator can be, it's a solid estimate based on project area, yarn weight and stitch type. Always make a gauge swatch if the project matters, and buy a spare skein in the same dye lot.
